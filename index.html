APPLY PATCH

xdeltaUI로 적용하기

  1. xdeltaUI 3.1을 실행하고 Apply Patch 모드를 선택합니다.
  2. 원본 일본판 ISO를 Source File로 선택합니다.
  3. V32 xdelta 파일을 Patch File로 선택합니다.
  4. 새 파일명으로 결과 ISO를 지정한 뒤 적용합니다.
  5. 생성된 ISO를 PPSSPP에서 실행합니다.

원본 ISO를 덮어쓰지 마세요. 반드시 별도의 출력 파일을 지정해야 합니다.
